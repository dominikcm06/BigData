# Tópicos de Big Data

Repositorio de prácticas y proyectos desarrollados durante la materia de **Tópicos de Big Data**.

## Descripción

Este repositorio contiene las prácticas, ejercicios y proyectos realizados durante el curso. Cada práctica se plantea como un proyecto de datos independiente, con sus propios datos, código, dependencias y entorno de ejecución.

El repositorio permite mantener un registro de la evolución del trabajo mediante Git y GitHub.

## Estructura del repositorio

Cada carpeta corresponde a una práctica o proyecto independiente:

```
Tópicos de Big Data/
│
├── U1_1_probabilidad_estadistica/
├── U1_2_...
├── U2_1_...
└── ...
```

Cada práctica incluye su propio `requirements.txt` y entorno virtual local (`.venv/`), que no se sube al repositorio.
